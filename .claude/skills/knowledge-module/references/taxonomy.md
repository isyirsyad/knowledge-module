# Fact Taxonomy — 11 categories

`type` is a retrieval tag, not a folder. A mis-tag is cheap to fix. Canonical
order (used for INDEX sorting is alphabetical by slug, but KNOWLEDGE.md
headings use THIS order):

1. `strategy` — vision, positioning, strategic bets, north-star goals
2. `market` — TAM, trends, segments, timing
3. `customer` — ICP, personas, needs, feedback, churn reasons
4. `product` — features, roadmap themes, differentiation
5. `competitive` — competitor moves, strengths, weaknesses
6. `gtm` — sales motion, marketing, pricing, channels, partnerships
7. `operations` — internal processes, delivery, systems, support
8. `people` — org, hiring, culture, key personnel
9. `finance` — revenue, costs, runway, fundraising, investors
10. `legal` — compliance, contracts, IP, regulatory, risk
11. `reference` — catch-all: definitions, links, uncategorized

When unsure, prefer `reference` over inventing a new category. New categories
may be added later without migrating existing facts.
